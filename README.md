One kind, funny fortune for a houseplant, written for make.fun's "Fortune in a Pot" bounty: a single line, 120 characters at most, about the plant's own future, in the cadence of a prediction.

## The line

> A tall stranger will water you soon — and this time they will remember the second glass. Good things grow slowly.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It sounds like a fortune, not a care instruction: a prediction about the plant's future, warm toward both plant and keeper, with no doom and no withering in it. The joke is gentle — the stranger who waters and forgets the second glass — and the closing line is the kind of small wisdom a fortune cookie would be proud of. It reads cleanly aloud, with no padding to reach the limit.
